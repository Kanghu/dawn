Hi everyone,
I’ve noticed that Shopify has started serving its own llms.txt (yourdomain.com/llms.txt) natively over the past few days. I couldn’t find anything in the changelog about it – if anyone has an official source, I’d appreciate the link.
This is a real problem for us: we had a URL redirect set up under /llms.txt pointing to a manually curated file. The redirect is still in place, but it’s no longer being honored – Shopify’s system-generated file is served instead. Our curated list has effectively become obsolete overnight.
My questions for the community:
Has anyone else run into this?
Has anyone found a way to override the system file or serve a custom llms.txt in front of it?
My main goal is just to get our curated content served. I’d be perfectly fine with Shopify appending its default entries (UCP notices etc.) below ours.
Thanks for any pointers!

#2 Nordalux (Shopify Partner) 2026-05-11T12:15:32.740Z staff=False
Update – solved.
The fix is to add templates/llms.txt.liquid to your theme, the same way you’d customize robots.txt.liquid. Whatever you put in that template is served at /llms.txt and overrides Shopify’s auto-generated content. Tested on our store – works as expected.
Credit goes to Jason in the Shopify Dev Community, who pointed this out in this thread: Llms.txt and agents.md - Agentic Commerce - Shopify Developer Community Forums
A few notes for anyone else running into this:
The old URL-redirect workaround (Admin → Online Store → Navigation → URL Redirects) silently stopped working once Shopify started serving /llms.txt natively. The redirect entry stays in the admin but is no longer honored – worth removing once the Liquid template is in place to avoid two conflicting mechanisms.
Shopify is also serving /agents.md natively. I haven’t tested whether a templates/agents.md.liquid hook exists – if anyone has, please share.
Shopify’s default /llms.txt content is essentially a sign-up prompt for Shopify, not a useful index of your store. So overriding it is strongly recommended if you care about how LLM crawlers see your shop.
Hope this helps the next person who runs into this.

Your About/brand snippet, top FAQs inline (not just linked), shipping and returns summary with concrete numbers, and collections grouped by intent (gift, use-case) rather than internal taxonomy.
